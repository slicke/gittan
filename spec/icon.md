# Application icon

Read this when touching the artwork, `make icons`, the .ico/.icns/PNGs or how the macOS bundle gets its icon.

- The artwork comes finished, a crossing red and green strand with a ring at each end on a dark rounded tile, drawn as SVG and exported to PNG by hand; nothing in the build draws or sizes it. `icons/gittan-mac.svg` and its export `icons/gittan-mac.png` (1024 pixels) are the macOS icon, the tile already on Apple's 824/1024 grid with its own drop shadow. `icons/gittan-linux.svg` (the larger sizes) and `icons/gittan-linux-small.svg` (a simpler drawing for the small ones) give `icons/png/gittan-<n>.png` at 16, 22, 24, 32, 48, 64, 128, 256 and 512 for Windows and Linux, the tile filling more of its canvas. `make icons` runs `tools/makeicons.swift` (macOS only: CoreGraphics and `iconutil`), which packs them: `icons/Gittan.icns` from `gittan-mac.png` scaled to each size, `Gittan.ico` from the PNGs of 16 to 256 as they are (it refuses one of the wrong size). A new artwork replaces those files and runs `make icons`. Commit the generated files; other platforms only consume them. The Linux release copies `icons/png/gittan-256.png` beside the binary as `gittan.png`.
- `Gittan.ico` beside `Gittan.lpi` is the project icon (`<Icon Value="0"/>` in the .lpi means it is set); Lazarus compiles it into the executable's resources, which the LCL uses for the window and taskbar icon on Windows and Linux.
- Lazarus creates `Gittan.app` without an icon, so the Darwin build targets in the Makefile copy `icons/Gittan.icns` into `Contents/Resources` and add `CFBundleIconFile` to `Info.plist` after lazbuild. The `Info.plist` lazbuild writes into a new bundle has the project title as `CFBundleName` with a bare `&`, which PlistBuddy refuses to read (so CI, which always starts without a bundle, shipped no icon); the targets escape it, set `CFBundleName` to Gittan and check the result with `plutil -lint`. A bundle built from the Lazarus IDE lacks the icon until the next `make`. Finder caches icons; `touch Gittan.app` or a relaunch of Finder refreshes it.
